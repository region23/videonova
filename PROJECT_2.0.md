# Техническое задание на разработку приложения VideoNova

## 1. Общее описание проекта

VideoNova — это кроссплатформенное десктопное приложение для автоматизированного перевода видео с YouTube и других видеоплатформ. Приложение позволяет пользователю загрузить видео с видеоплатформы, извлечь из него аудио, распознать речь, перевести субтитры на другой язык, синтезировать речь на целевом языке и создать новую версию видео с переведенной аудиодорожкой и субтитрами.

## 2. Техническая архитектура

### 2.1. Платформа и фреймворки
- **Tauri 2.x**: основной фреймворк для создания кроссплатформенных приложений с использованием Rust для бэкенда и веб-технологий для фронтенда
- **Rust**: язык программирования для бэкенда (версия "edition": "2024")
- **Vue 3 Composition API**: JavaScript-фреймворк для фронтенд-части
- **TypeScript**: типизированный JavaScript для фронтенд-разработки
- **PrimeVue v4**: библиотека компонентов для пользовательского интерфейса

### 2.2. Архитектура приложения
- **Фронтенд (Vue.js)**:
  - Отвечает за пользовательский интерфейс
  - Взаимодействует с бэкендом через Tauri API
  - Отображает прогресс выполнения операций
  - Тонкий фронтенд с минимумом бизнес-логики

- **Бэкенд (Rust)**:
  - Основная логика приложения
  - Управление внешними инструментами и API
  - Обработка аудио и видео
  - Асинхронное выполнение операций

## 3. Основные функциональные возможности

### 3.1. Загрузка видео
- Получение информации о видео по ссылке YouTube или любой другой, поддерживаемой утилитой yt-dlp
- Определение языка исходного видео по метаданным полученным через yt-dlp (если доступны)
- Загрузка видео и аудио с использованием yt-dlp
- Отображение прогресса загрузки
- Возможность отмены загрузки

### 3.2. Распознавание речи
- Извлечение аудиодорожки из видео
- Разделение вокальной дорожки и инструментальной дорожки (включая интершумы и все остальные звуки кроме голоса) с помощью библиотеки Demucs
- Распознавание речи с использованием OpenAI Whisper API
- Сохранение результатов в формате VTT (субтитры)


### 3.3. Перевод текста
- Перевод субтитров с использованием OpenAI API
- Адаптация перевода под временные рамки исходного аудио
- Сохранение переведенных субтитров в формате VTT

### 3.4. Синтез речи
- Использование OpenAI TTS API для качественного синтеза речи
- Генерация голосовой аудиодорожки на основе переведенного текста
- Регулировка скорости и тона речи для лучшей синхронизации с помощью Soundtouch.


### 3.5. Обработка и объединение видео
- Использование ffmpeg для финальной обработки
- Объединение новой аудиодорожки с инструментальной аудиодорожкой, полученной на шаге "Распознавание речи"
- Объединение исходного видео с новой микшированной аудиодорожкой и установка этой дорожки в видео как основной
- Добавление субтитров (оригинальных и переведенных)
- Возможность выбора формата выходного видео

### 3.6. Управление зависимостями
- Автоматическая проверка наличия необходимых внешних инструментов (yt-dlp, ffmpeg, Demucs, Soundtouch)
- Автоматическая загрузка и обновление внешних инструментов при необходимости
- Проверка доступночти ресурсов API OpenAI и YouTube. В случае недоступности показывать рекмендацию включить VPN.
- Управление зависимостями должно выполняться при запуске приложения


## 4. Внешние зависимости и интеграции

### 4.1. Внешние API
- **yt-dlp**: для получения информации о видео
- **OpenAI API**: для распознавания речи, перевода текста и синтеза речи

### 4.2. Внешние утилиты
- **yt-dlp**: для загрузки видео с YouTube
- **ffmpeg**: для работы с аудио и видео файлами
- **Demucs**: для разделения голоса и инструментальной дорожки
- **Soundtouch**: для выравнивания тона и изменения скорости аудио
- **Whisper, Vosk**: Распознавание голоса и перевод в текст
- **Fish Speech**: Text to speech локальная модель
- **Ollama**: Для запуска локальных LLM

### 4.3. Библиотеки Rust
- **tokio**: для асинхронного выполнения задач
- **reqwest**: для HTTP-запросов
- **serde**: для сериализации/десериализации данных

### 4.4. Плагины Tauri
- **tauri_plugin_clipboard_manager::ClipboardExt**: для работы с буфером обмена
- **tauri_plugin_store::StoreExt;**: для хранения настроек
- **tauri_plugin_opener::OpenerExt;**: для открытия файлов
- **tauri_plugin_dialog**: для диалоговых окон
- **stronghold**: Store secrets and keys using the IOTA Stronghold secret management engine.

## 5. Обработка аудио и синхронизация

### 5.1. Особенности обработки аудио
- Нормализация аудио
- Изменение скорости речи для синхронизации с оригиналом
- Сохранение эмоциональной окраски голоса

### 5.2. Синхронизация аудио с видео
- Настройка скорости воспроизведения синтезированной речи
- Адаптация длительности отдельных фрагментов речи
- Обработка пауз между предложениями

## 6. Пользовательский интерфейс

### 6.1. Главный экран: окно ввода данных (слева)
- Поле для ввода ссылки на видео
- Выбор директории для сохранения результатов
- Выбор исходного и целевого языков
- Кнопка для запуска процесса обработки (после запуска кнопка меняет функционал на кнопку отмены операции)

### 6.2. Экран настроек
- Добавление API-ключа OpenAI
- Выбор SpeechToText: OpenAI или локальная модель (например Whisper, Vosk)
- Выбор LLM для перевода: OpenAI или локальная модель на базе Ollama (например Qwen 2.5)
- Выбор TTS: OpenAI или локальная модель (например Fish Speech)
- Настройки качества видео и аудио
- Настройки голоса для синтеза речи
- При выборе в настройках локальных моделей необходимо предупреждать пользователя, что она будет скачана и надо подождать. Реализовать экран скачивания и установки

### 6.3. Главный экран: Отображение прогресса (справа)
- Пошаговое отображение текущего этапа обработки
- Прогресс-бар для каждого этапа
- Вывод логов и ошибок
